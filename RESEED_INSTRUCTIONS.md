## Полная очистка и посев БД

> ⚠️ **Внимание:** Это удалит **ВСЕ** данные из базы!

### Шаг 1: Очистка базы данных

```bash
# Полная очистка всех таблиц и повторный посев
php artisan db:wipe && php artisan migrate --seed
```

Эта команда:
1. `db:wipe` — удаляет все таблицы из базы данных
2. `migrate` — заново создаёт все таблицы из миграций
3. `--seed` — запускает `DatabaseSeeder`, который вызывает все сидеры по порядку

### Шаг 2 (альтернатива): Только пересев без удаления таблиц

Если вы хотите **не удалять таблицы**, а только очистить данные:

```bash
# Обновить миграции (если есть новые) и запустить сидеры
php artisan migrate:fresh --seed
```

> `migrate:fresh` = `db:wipe` + `migrate` — это то же самое, что команда выше.

### Шаг 3: Запуск конкретного сидера (если нужно только что-то добавить)

```bash
# Запустить только сидер заявок
php artisan db:seed --class=TicketingSeeder

# Запустить только сидер справочника устройств
php artisan db:seed --class=DeviceDictionarySeeder
```
